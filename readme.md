# カレンダーテキスト生成プロジェクト

このプロジェクトは、カレンダーアプリで使用するための日付データ（新暦・旧暦・行事・節気）を特定のテキスト形式で生成するためのリファレンスセットです。
AIだけで日付を作成せず、内閣府・国立天文台・AJNET（日本カレンダー事務局）などの信頼できる暦データを元に作成します。
AIは文章整形、形式チェック、差分確認の補助として使用します。

## ファイル構成

このドキュメントセットは以下のファイルで構成されています。

* **rules.md**: カレンダーデータの作成に関する全ての詳細ルール。
    * 4種類の出力ファイル（`weekday.txt`, `youbi.txt`, `kyureki.txt`, `cell.txt`）のフォーマット定義。
    * 日本の国民の祝日、旧暦、24節気、雑節（彼岸）、および年間行事の記載ルール。
    * 年間行事予定表PDFの1日1セル表示に合わせた統合テキストの作成ルール。
    * 十干十二支の対応表。

## 作業時の重要事項

1.  **正確性の確保**:
    旧暦の月の始まり（朔日）や24節気の正確な日付は年によって変動します。データ作成時は必ず **国立天文台 暦計算室** や **AJNET（日本カレンダー事務局）** などの信頼できる天文暦データと照合してください。
2.  **閏月の扱い**:
    閏月が発生する年は、ルールの「閏月がある年」の項目に従い、焼香礼拝日の追加や月名の表記変更を正しく行ってください。
3.  **雑節の計算**:
    「彼岸入り」「彼岸明け」は春分・秋分の日を基準に自動的に算出・記載します。
4.  **祝日の扱い**:
    祝日は日本の国民の祝日・休日を対象とし、内閣府が公開するCSVを基準データにします。

## 生成されるテキストの用途

生成された4種類のテキストファイルは、カレンダーアプリの各表示レイヤー（日付表示、行事表示、旧暦表示）と、年間行事予定表の1日1セル表示に取り込まれることを想定しています。

## LunaCalendar テキスト生成ツール

このリポジトリには、Illustratorへ流し込むためのテキストを作る簡易Webアプリを含みます。

GitHubリポジトリ:

https://github.com/mahorobach/luna-calendar.git

### 開き方

Cloudflare Pagesに公開したURLをブラウザで開きます。

```text
https://<project-name>.pages.dev/
```

`index.html` を直接開くこともできますが、その場合は公式データ取得ボタンではなく、確認済みCSVの貼り付けまたはCSV読込を使います。

Cloudflare Pagesでは、以下のFunctionsが公式データ取得に使われます。

```text
/api/holidays?year=2027
/api/solar-terms?year=2027
```

### 入力CSV

Cloudflare Pagesで開いた画面の「公式データ取得」から、対象年の祝日と24節気を取得できます。

CSVファイルだけを作りたい場合は、ターミナルで以下を実行します。

```bash
node tools/fetch-official-data.mjs 2027
```

生成先:

```text
data/generated/2027/holidays.csv
data/generated/2027/solar_terms.csv
```

旧暦CSVは、AJNET（日本カレンダー事務局）などで確認したデータを別途用意してください。
旧暦の日付はアプリやAIで推測しません。

祝日:

```csv
date,name
2027-01-01,元日
```

24節気:

```csv
date,name
2027-01-05,小寒
```

旧暦:

```csv
date,lunar_month,lunar_day,leap
2027-01-01,12,24,false
```

年間行事:

```csv
type,month,day,name
lunar,1,1,旧正月節・弥勒祖師聖誕日
lunar-last,12,,旧大晦日
gregorian,1,1,［丁未年］
```

### 出力

対象年・月を選んで「生成」を押すと、以下の4種類を作成します。

- `weekday.txt`
- `youbi.txt`
- `kyureki.txt`
- `cell.txt`

旧暦表記は `rules.md` の表記ルールに従います。24節気・祝日・旧暦の日付そのものは自動推測せず、入力CSVの確認済みデータを使用します。

### 現在の実装状況

- `index.html`、`styles.css`、`app.js` で構成された静的Webアプリ。
- Cloudflare Pagesで公開し、Functions経由で祝日と24節気を取得できる。
- ブラウザから直接開く場合は、公式データ取得ではなくCSV入力を使う。
- 祝日、24節気、旧暦、年間行事のCSV入力に対応。
- 1か月分または12か月分の `weekday.txt`、`youbi.txt`、`kyureki.txt`、`cell.txt` を生成。
- 生成結果は画面上で確認し、コピーまたは `.txt` 保存できる。
- JavaScriptの構文確認は `node --check app.js` で実施済み。
